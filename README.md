## Projects Featured

### Rent Zimbabwe
A property discovery platform connecting Zimbabwean property seekers with landlords through web and WhatsApp. Built with Expo/React Native, Supabase, and TypeScript.

### WA Directory
A conversational business directory using WhatsApp Business API and Gemini AI for natural language discovery in Zimbabwe.

### AI Coding Agent Harness
A structured workflow for AI-assisted development with human-led validation, designed for production-grade agent systems.

### Cybersecurity Labs
Security knowledge documentation covering threat modeling, secure coding practices, and vulnerability management.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
# Open http://localhost:3000

# Build for production
npm run build

# Start production server
npm run start

# Run linter
npm run lint
```
